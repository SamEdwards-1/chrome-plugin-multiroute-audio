Audio device access

Chrome only offers outputs it can enumerate and use. A hardware channel is selectable only when its driver exposes a separate browser output endpoint.

The microphone action asks Chrome for temporary input access to reveal device labels. The temporary track is stopped immediately and is never connected to a route. You can decline and still try the system default.
